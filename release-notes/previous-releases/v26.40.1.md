# v26.40.1

> [!WARNING]
> Mods only work in Claude Code 2.1.287 or newer. In other tools, such as Copilot CLI, the panes do not appear.

- `reports`: `/report-pane` mod, a Power BI report tree in the Claude Code sidebar that follows `pbir`: pages, visuals, bookmarks, filters and report measures, with highlights of what Claude reads or changes
- `fabric-data-app`: new plugin with the `/data-app-pane` mod, every Fabric App under the working directory with its data sources, deploy state and files, following `rayfin`
- All panes: the domain, workspace or folder that Claude touches stays pinned instead of scrolling away, highlights on rows already in view no longer scroll the tree, Claude's commands never move your selection, the search row shows "Claude is working in ..." while a command runs, the hover bar is fainter than the selection, and names with spaces work in the pane commands
