# v26.40.4

- Added a Tabular Editor 3 C# script example, `examples/ui/set-ui-font-size.csx`, that sets the TE3 desktop UI font and size for the current session.
- Fabric pane: tenant at the top with tenant settings (state, default, recommendation, risk, docs link), domain and capacity grouping with SKU, Fabric Trial and PPU names, paused or running state, and capacity details with Azure cost and resource links.
- Fabric pane: workspace folders and every item, including Fabric apps that `fab ls` omits; tenant-wide search with `fab find`; double-click opens an item in Fabric, reports through their reportEmbed link (`reportLinks` option switches to portal links).
- Fabric pane: Claude's `fab` calls light folders, items inside folders and apps, matched by path or GUID; a Claude working line with spinner; braille spinners left of what loads; fonts re-detected on open.
- Fabric pane on desktop: native rows with Fabric icons, indent guides, native scrolling and a collapsible Properties row under the selection.
- Report pane: the Fabric pane design, a properties panel with actions, double-click opens the file behind any object, the semantic model opens its deployed item, Open in Fabric uses the reportEmbed link on the chosen page, and the theme expands into colors, text classes and visual styles from the * wildcard down to each property.
- Fabric app pane: the Fabric pane design, lists the SQL database, SQL endpoint and user data functions an app deployed, double-click opens the deployed model, SQL item or function, and Claude's commands naming an app or item GUID light that row.
- organize-semantic-model: new skill for table groups, folders, naming, hierarchies, sorting, hiding, descriptions and annotations in near ASD-STE100 style, formats and DAX formatting.
- fabric-cli no longer ships the fabric-sql MCP server; T-SQL goes through `query_sql_endpoint.py`.
- pbir-cli docs: fixed stale catalogue counts, path suffixes and roundtrip guidance.
