# v26.30.1

## Statusline: Opus 5 gets the full effort range

The Opus effort-dots gate in `useful-stuff/status-lines/statusline.sh` was a hardcoded 4.7-4.19 regex, so Opus 5 fell into the legacy 4-dot scale with no `ultracode`.

- Opus is now gated with the same `_effort_ge "4.7"` version compare as the Haiku and Sonnet branches, so Opus 5 renders all six levels: low/medium/high/xhigh/max dots plus the purple `ultracode` diamonds
- Version detection strips 8-digit date segments from the model id before deriving the version, so dated ids without a minor version (`claude-opus-4-20250514`, `claude-3-opus-20240229`) no longer read the date as a version and slip past the gate; plain Opus 4 also displays as `Opus 4` instead of `Opus 4.20250514`
- The README effort-dots section now matches current behavior (ultracode diamonds, Haiku 4.5+ effort levels)
