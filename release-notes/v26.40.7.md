# v26.40.7

- New plugin `dashboards` for Claude Dashboards on Fabric and Power BI semantic models:
  - `querying-fabric`: DAX (and T-SQL) through the Fabric connector. Reuses the model's measures instead of writing new ones, gives every KPI a target and a trend, crossfilters every visual through query parameters, and covers DAX query syntax, time intelligence and a test loop. Derived from the `dax-authoring` skill Microsoft ships with Fabric Apps. Tested in claude.ai with and without the skill on the same prompt; eval in `skills/querying-fabric/evals/`.
  - `creating-good-dashboards`: never resolve comments yourself, reply in a few short bullets, and visual style after Stephen Few and Edward Tufte.
- README: every plugin has a logo in its dropdown.
- Semantic models and reports (from v26.40.6): DAX and model metadata write columns as `'Table'[Column]` with the table always quoted, and measures as `[Measure]` with no table in front.
