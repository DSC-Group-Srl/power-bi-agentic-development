# v26.40.0

> [!WARNING]
> Mods only work in Claude Code 2.1.287 or newer. In other tools, such as Copilot CLI, the panes do not appear.

- `fabric-cli`: `/fabric-pane` mod, a Fabric workspace tree in the Claude Code sidebar that follows `fab`: highlights what Claude reads, downloads, uploads or changes, groups workspaces by domain, expands lakehouses, navigates on double-click, and passes the selected item to Claude as context
- `databricks-cli`: new plugin with the `/databricks-pane` mod, the same pane for the `databricks` CLI (workspace, Unity Catalog, compute, jobs, pipelines, apps, dashboards)
- Pane options: `glyphs`, `follow` (Follow Claude) and `fontHint`; brand icons come from [FabricSymbols NF](https://github.com/data-goblin/fabric-nf) and [DatabricksSymbols NF](https://github.com/data-goblin/databricks-nf)
